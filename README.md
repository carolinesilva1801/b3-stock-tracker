# B3 Stock Tracker Dashboard

## Overview
The B3 Stock Tracker Dashboard is designed for swing trading enthusiasts who aim to leverage market analytics to achieve greater than 7% profit. This dashboard provides real-time insights into stock movements, helping traders make informed decisions.

## Features
- **Profit Analysis**: Analyze stocks for potential profits exceeding 7% based on historical data and current market trends.
- **Browser Notifications**: Get instant notifications for significant market changes or stock performance updates directly in your browser.
- **User-friendly Interface**: Navigate through the dashboard with ease, allowing for quick access to the tools you need for effective trading.

## Getting Started
To get started with the B3 Stock Tracker Dashboard, follow these steps:
1. **Clone the repository**: Use the command `git clone https://github.com/carolinesilva1801/b3-stock-tracker.git` to clone the repository to your local machine.
2. **Install Dependencies**: Navigate into the project folder and run `npm install` to install the necessary dependencies.
3. **Run the Dashboard**: Start the application with `npm start` and open your browser to view the dashboard.

## Usage
- Monitor stocks and receive notifications for stocks that are projected to rise by more than 7%.
- Utilize the analysis tools to track your investments and make timely decisions.

## Conclusion
The B3 Stock Tracker Dashboard is a powerful tool for traders looking to maximize their gains in the stock market. By utilizing this dashboard, traders can stay ahead of market trends and make informed trading decisions.
